## Ⅰ. About

<img align="right" width="220" src="https://skillicons.dev/icons?i=figma,react,ts,tailwind,nextjs&theme=dark" />

Front-end developer focused on building production-oriented web interfaces with **React**, **Next.js**, and **TypeScript** — and a designer's eye for the details that make an interface feel intentional. I work across the full front-end lifecycle: from Figma handoff to a responsive, accessible, type-safe component in production.

What I care about:

- **Design → Code fidelity** — pixel-accurate implementation without losing performance
- **Component architecture** — reusable, composable, easy to reason about
- **Type safety** — TypeScript as a design tool, not an afterthought
- **Responsive by default** — mobile, tablet, and desktop treated as first-class, not an edit pass

1. 🚀 **Advanced React & Next.js** — Deepening my knowledge of Next.js App Router, Server Components, data fetching, and scalable application architecture
2. 🧩 **Frontend Architecture** — Building reusable component systems, clean folder structures, and maintainable TypeScript codebases
3. 🎨 **UI/UX & Design Systems** — Improving design-to-code workflows, component consistency, responsive interfaces, and high-fidelity UI implementation
